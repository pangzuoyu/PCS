# （已被替代）状态点之间通过设备关联，设备计算自动产生下游状态点

初稿设计：stream_state_points 携带 upstream_state_point_id + equipment_id，设备计算产生下游状态点，长输管道支持沿程剖面（距离-压力-温度数组）。

被替代原因：用户指出**物流代码经过设备后会更换**（S-101→泵→S-102）。把设备连接放在同一物流的状态点之间，意味着一条物流贯穿多设备，与工程实践（P&ID/PFD 上每个设备之间的管段有独立物流编号）不符。正确模型见 ADR-0022：设备是**物流之间**的转换函数，位置变化用不同物流表达，工况变化才用状态点。

保留遗产：沿程剖面（profile_json）保留在 stream_state_points 中，仅用于长输管道场景。
