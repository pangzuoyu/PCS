## 根因分析

### PCS 当前口径（物理自洽）

```
annual_total_energy (MJ)
  = 电 kWh × 3.6                                (SI 定义, 不用折标)
  + 燃料气 Nm³ × toe_factor(分类) × 41.868       (ISO 1 toe = 41.868 MJ)
  + 蒸汽 t  × toe_factor(分类) × 41.868          (同上)
  + 水 t × 0 + 工艺气体 Nm³ × 0 + 低温余热 GJ × 1000
```

**自洽性验证**：
- `total_toe × 1000 × 41.868 = 1,194,615,319 MJ`
- PCS 计算值 `= 1,194,575,469 MJ`
- 相对偏差 `0.003%`（差异来自电按 SI 3.6 MJ/kWh 而非折标 0.086×41.868=3.60，两口径几乎等价）

→ **PCS 的 toe / coal / MJ 三个指标内部完全自洽，符合 GB/T 2589 + ISO 标准。**

### XLS 参考值的隐含口径

```
XLS 隐含发热量 = 1,242,159,527.8 MJ / 28,532.8967 t = 43.5343 MJ/kg 标油
ISO 标准       = 41.868 MJ/kg 标油
偏差           = +1.6663 MJ/kg (+3.98%)
```

### 差异无法归因到单一能源类别

| 假设 | 需要的附加量 | 是否合理 |
|------|-------------|---------|
| 全部归燃料气 | +1.9269 MJ/Nm³（PCS 已有 35.588，R0 硬编码是 38） | ⚠️ 勉强接近 R0，但 R0 是被判定为错误的 |
| 全部归蒸汽 | +1603.8 MJ/t（PCS 已有 3182，R0 硬编码 2778） | ❌ 蒸汽 1.0 MPa 潜热约 2778 MJ/t，加 1604 不合理 |
| 全部归电 | +1.1966 MJ/kWh（PCS 已有 3.6） | ❌ 电热当量定义值就是 3.6 MJ/kWh（1 kW·h = 3.6 MJ），不可能更高 |

**结论**：XLS 的 43.53 MJ/kg 标油不是某个能源类别的显热/潜热叠加，而是**XLS 自身的折标发热量取值
与 GB/T 2589-2020 + GB 30251-2024 不同**（或 XLS 用了未在 PCS CONFIG 表中的辅助能，如
燃料气伴生气/火炬气/蒸汽凝液回收热）。

## 三个待裁决选项

### 选项 A：XLS 基准值修正（推荐）

**依据**：GB/T 2589-2020 + GB 30251-2024 附录 A（工艺室 2026-10-08 R1 已 5 签齐）明确规定
1 kg 标油 = 41.868 MJ。XLS 的 43.53 与之不符。

**动作**：请工艺室核对蜡油加氢 XLS（1216D132）中"年总能耗"的计算公式，确认其折标发热量取值来源。
若 XLS 用的是旧版或不规范取值，应更新 XLS 基准为 `toe × 41.868`。

**结果**：PCS 三个指标全部 PASS（toe/coal 已 PASS，MJ 会自动 PASS）。
**封版路径**：工艺室出具基准修订说明 → 更新脚本 `xls_reference["annual_total_energy_mj"]`
→ 重跑验收 → 三项全 PASS → T5 正式封板。

### 选项 B：PCS 口径改为兼容 XLS

**动作**：在 CONFIG 表加一列 `energy_mj_per_toe`（XLS 口径 43.5343），MJ 计算改为查该列。

**代价**：违背 GB/T 2589-2020 国际标准；PCS 三个指标不再内部自洽（toe×41.868 ≠ PCS MJ）。
**不推荐**——除非工艺室能出示 XLS 口径的规范依据。

### 选项 C：MJ 指标降级为"参考值"（不作为验收门槛）

**动作**：验收脚本只对 toe / coal 判定 PASS/FAIL，MJ 仅打印供人工参考。

**代价**：失去"年总能耗"这一维度的机器校验。**不推荐**——但若工艺室短期无法裁决，
可作为**临时封板**方案（toe/coal 已精确 PASS，MJ 差异已查清并归档）。
