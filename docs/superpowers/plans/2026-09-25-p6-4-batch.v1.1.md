```python
class TwoPhaseSeparatorSizingResult:
    vessel_shape: str
    oil_vol_rate_bbl_d: float       # 油体积流量 = oil_mass_rate / (oil_density × conversion)
    water_vol_rate_bbl_d: float     # 水体积流量 = water_mass_rate / water_density
    gas_vol_rate_mmscfd: float      # 气体积流量 = gas_mass_rate / gas_density（标准状态）
    mixed_density_kg_m3: float      # 混合相密度（体积加权平均）
    vmax_m_s: float                 # Vmax = K × √((ρL - ρV) / ρV)，源自 WS-CA-PR-010 Rev A §4.2（基于 Souders-Brown）
    csa_min_m2: float               # **WS-CA-PR-010 §4.3**：最小 CSA = Q_gas_volumetric / (3600 × Vmax × 0.85)，0.85 为工程惯例安全系数（保留 15% 余量）
    csa_actual_m2: float            # 实际 CSA = π × D² / 4
    nozzle_inlet_min_id_m: float    # **WS-CA-PR-010 §5.1**：nozzle_id = √(4 × m_inlet / (π × v_nozzle × ρ_mix))，v_nozzle 由动量限值反推（F = m·v ≤ F_max → v = F_max / m）
    nozzle_outlet_min_id_m: float   # 同上，出口
    control_height_m: float         # **WS-CA-PR-010 §5.3**：H_c = t_c × Q_total_volumetric / (3600 × CSA)，对应 SPEC §3.4.2 仪表间距
    control_volume_m3: float        # 控制液位对应体积（partial volume at H_c，T3 calc_partial_volume 调用）
    residence_time_s: float         # V_total / (Q_total_volumetric / 3600)，实际停留时间
    imperial_conversion: dict[str, float] | None
    formula_ref: dict[str, str]     # WS-CA-PR-010 Rev A §3~§5 + SPEC §3.4.2
```

**5 段计算**（C-08 sizing 路径，区别于 V1.0 weight 4 段）：
```
1. 油/水/气体积流量    = mass_rate / density（bbl/d, MMscfd）
2. 混合相密度          = weighted average over volume fractions
3. Souders-Brown Vmax  = K × √((ρL - ρV) / ρV)
4. 气相 CSA 校核       = min_csa (85% 利用率) ≤ actual_csa (πD²/4)
5. 喷嘴动量校核        = nozzle_id ≥ √(4 × Q / (π × V_max_nozzle))
   + 仪表控制高度/停留时间 = f(t_response, V_total, CSA)
```

**收敛算法**：
- 首选 Newton（O(收敛²)）；fallback bisection（O(log N)，无需 Jacobian）

- 最大迭代 50 次；超限抛 `MassIterationNotConvergedError`（422）
