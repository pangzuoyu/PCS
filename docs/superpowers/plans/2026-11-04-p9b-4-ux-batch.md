```ts
/**
 * 批次「提交校对」的状态持有者（P9B-4 · TODO-116）。
 *
 * ## 为什么要有这个 hook（而不是继续用组件局部 state）
 *
 * P9B-3b 的 `batchResult` 是**组件局部 state** ⇒ 关闭摘要弹窗即丢 ⇒
 * 「50 条里 8 条失败，用户要重试得回列表逐条找」⇒ 批量操作最容易劝退人的
 * 地方就是「失败后要手动重来」。
 *
 * ⇒ 失败清单提升到 **hook**（页面唯一的消费者 ⇒ 不需要全局 store）。
 *
 * ## 重试语义（裁决）
 *
 * - **只重试上次的失败项** —— 成功的那些已经提交过了，重发是浪费。
 * - 重试后**失败清单替换**为本次重试的失败清单（最可预测的语义：
 *   「上次失败、这次不再失败」的条目从清单里消失）。
 * - ⚠️ **不需要**后端区分「我重试成功的」与「被别人抢跑的」——
 *   摘要里已有一行「其中 M 条本来就在审批中（幂等命中 · 本次未提交）」
 *   （TODO-124）⇒ 幂等命中会**如实显示** ⇒ 用户不会误以为是自己重试生效的。
 *
 * ## 已知限制
 *
 * ⚠️ 刷新页面会**丢失**失败清单（内存态，与本仓 auth store 同款取舍）⇒
 * UI 上如实提示。
 *
 * ⚠️ `onDone` = 刷新列表 ⇒ 重试后**列表内容可能变**（失败项可能已不在
 * 当前筛选结果里）⇒ 这是**期望**的（后端返回的是最新态）。
 * ⚠️ **不会「跳页」** —— 本仓物流列表 `pagination={false}`（无分页）⇒
 * 刷新不涉及页码。（若将来给列表加分页，此处要重新审视。）
 */
```

- `submit(streamIds)`：`setSubmitting(true)` → 调 `streamApi.batchSubmitForReview(streamIds)` → `setResult(res)` → `setFailedIds(res.failed.map(f => f.stream_id))` → `await options?.onDone?.()`（刷新列表）→ `finally setSubmitting(false)`

`pcs-backend/app/services/stream_service.py`：

```python
    @staticmethod
    async def reference_counts(
        db: AsyncSession, stream_ids: Sequence[uuid.UUID]
    ) -> dict[uuid.UUID, int]:
        """一批物流各自的**被引用数**（P9B-4 · TODO-108 · SPEC §7.7.1「引用 📎×N」）。

        **口径（钉死）** = 下游物流数 + 闪蒸结果数：

        | 引用方 | 表 | 关系 | 计入 |
        |---|---|---|---|
        | 下游物流 | `streams.upstream_stream_id` | 别的物流把本物流当上游 | ✅ |
        | 闪蒸结果 | `flash_results.stream_id` | 计算结果引用本物流 | ✅ |
        | 状态点 | `stream_state_points.stream_id` | 物流自己的工况点（**子表**） | ❌ |
        | 设备 | `sim_unit_op.*_streams_json` | JSONB 数组里的 id（**无索引**） | ❌ 延后 |

        ⚠️ **与删除门禁 `_collect_references` 的口径不同**（那边**含**状态点，
        因为状态点会阻塞删除）⇒ 两个数字**不要**混用 ⇒ SPEC 里要写清。

        ⚠️ **两条聚合查询**（整个列表 2 次往返）⇒ **不是 N+1**。
        """
```

实现（两条 `GROUP BY`）：

```python
        from sqlalchemy import func, select

        from app.models.calc import FlashResult

        if not stream_ids:
            return {}
        ids = list(stream_ids)
        counts: dict[uuid.UUID, int] = {sid: 0 for sid in ids}

        # ① 下游物流
        downstream = (
            await db.execute(
                select(Stream.upstream_stream_id, func.count())
                .where(Stream.upstream_stream_id.in_(ids))
                .group_by(Stream.upstream_stream_id)
            )
        ).all()
        for upstream_id, n in downstream:
            counts[upstream_id] += n

        # ② 闪蒸结果
        flash = (
            await db.execute(
                select(FlashResult.stream_id, func.count())
                .where(FlashResult.stream_id.in_(ids))
                .group_by(FlashResult.stream_id)
            )
        ).all()
        for sid, n in flash:
            counts[sid] += n

        return counts
```

⚠️ `func.count()` 无参数 ⇒ PG 返回 `count(*)`；SQLite 同理。
