P4.5 前端补课 Sprint 实施计划 V1.0
执行方式：superpowers TDD（每 task：RED 测试 → GREEN 实现 → commit）；可用 subagent-driven-development（每 task 派新 agent）或 executing-plans（本 session 批量）。
基线：P0（脚手架/登录/空布局）+ P1（StatusTag/WorkspaceSwitcher/ChecklistDashboard 三组件）+ P2/P3/P4 后端全部完成，前端 0 页面。
并行：与 P5 后端（VESSEL/SEP_EQUIP/PSV/HEAT）同时启动，不串行。
依赖：P4.5 的批 0/1/2 必须在 P5 首端点冻结前完成，否则 P5 页面无法复用组件库。

Goal：三周内把前端从「P0 半成品」拉到「P4 可开页面」——冻结 UI Spec、设计令牌、OpenAPI 类型、meta API、Mock Server、13 个跨模块组件、SchemaForm、CONFIG 六类资产前端。P5 期间并行补 P3/P4 全部页面。

Architecture：深色工程主题（tokens.css + AntD ConfigProvider 映射）→ OpenAPI 类型自动生成 + CI 漂移 → meta API 驱动枚举/权限/错误/状态机 → MSW Mock + Seed → 13 组件 + SchemaForm → CONFIG 页面 → P3/P4 页面并行补。

Tech：React 18 + TS 5 + AntD 5 + Zustand + React Router v6 + TanStack Query v5 + @rjsf/core + @rjsf/antd + MSW + Vitest + @testing-library/react + Playwright + openapi-typescript + Storybook（仅组件库）。

全局约束
UI Spec 为唯一依据：所有页面、组件、状态、颜色、文案以 docs/PCS-UI-SPEC.md 为准；与 OpenAPI 冲突时以 OpenAPI 为准（登记修订）。

禁止硬编码：字段名、枚举值、权限码、错误码、颜色值、间距值一律来自 Schema / meta API / tokens。

类型来源唯一：所有 API 类型来自 openapi-typescript 生成的 src/types/api.d.ts，禁止手写 interface。

表单驱动：所有业务表单用 SchemaForm（Pydantic JSON Schema + uiSchema），禁止手写字段列表。

CI 硬门：tsc --noEmit 0 error / eslint 0 error / vitest 全绿 / OpenAPI 漂移 fail / 表单↔Schema 漂移 fail。

tokens 优先：禁止在组件中硬编码 #xxx、16px、4px 等，一律走 CSS 变量。

等宽强制：所有数值、位号、哈希、管道号、Rev、doc_no 用 --font-mono。

8 态激活子集：P3 模块只显示 DRAFT/IN_APPROVAL/CHECKED/OBSOLETE；P4+ 显示 9 态全集。

门禁前置：不可执行操作禁用 + Tooltip；非 FORMAL 工作区隐藏批准/交付物/变更单。

性能预算：页面切换 ≤500ms / 表格 1000 行 ≤1s / 血缘图 100 节点 ≤2s。
