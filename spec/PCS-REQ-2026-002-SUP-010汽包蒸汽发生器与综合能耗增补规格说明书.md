第一部分：引言
1.1 增补目的
本增补文件基于两份工程计算文件（汽包工艺计算、综合能耗计算）以及新增的热虹吸蒸汽发生器安装高度计算文件，对 PCS 系统的以下模块进行数据模型对齐：

汽包/蒸汽发生器：炼油/化工装置中常见的汽包工艺计算，包含旋分器设计、给水管/下降管/上升管设计、蒸汽空间容积负荷校核等；

热虹吸循环安装高度：卧式/立式热虹吸蒸汽发生器的壳程压力平衡计算，确定汽包与蒸汽发生器之间的标高差及安装尺寸；

综合能耗：电力、燃料气、蒸汽、水、气体、低温余热等能耗项目的统计与折算（kg标准油/t）。

3.5 新增：热虹吸循环安装高度计算表
sql
CREATE TABLE thermosiphon_circulation_results (
    id UUID PRIMARY KEY,
    project_id UUID NOT NULL REFERENCES projects(project_id),
    workspace_id UUID NOT NULL REFERENCES workspaces(workspace_id),

    -- 基本标识
    equipment_tag VARCHAR(50) NOT NULL,           -- 蒸汽发生器编号（如 E-106）
    equipment_name VARCHAR(200),                  -- 设备名称
    circulation_type VARCHAR(30) NOT NULL,        -- 循环类型：HORIZONTAL / VERTICAL

    -- 主要几何参数
    shell_diameter FLOAT,                         -- 壳体壳径 Ds（m）
    drum_diameter FLOAT,                          -- 汽包直径（m）
    drum_liquid_level FLOAT,                      -- 汽包液位高 H1（m）

    -- 计算结果
    installation_height_calc FLOAT,               -- 计算安装高度 Hx（m）
    installation_height_final FLOAT,              -- 最终安装高度 Hxo（取余量后，m）
    safety_factor FLOAT DEFAULT 1.5,              -- 安全余量倍数
    check_result VARCHAR(20),                     -- 校核结果：PASS / FAIL
    circulation_drive_ratio FLOAT,                -- （立式）循环推动力/总压力降之比

    -- 详细参数（JSONB 存储，以适应卧式/立式差异）
    inlet_pipe_params JSONB,          -- 入口管线参数：{mass_flow, density, velocity, inner_diam, equivalent_length, friction_factor, reynolds, pressure_drop_constant, ...}
    outlet_pipe_params JSONB,         -- 出口管线参数：{velocity, inner_diam, equivalent_length, friction_factor, reynolds, vapor_fraction, mixture_density, mixture_viscosity, pressure_drop_constant, ...}
    shell_side_params JSONB,          -- 壳程参数：{avg_density, static_head, friction_drop, flow_area, baffle_spacing, baffle_count, ...}
    other_params JSONB,               -- 其他参数（如立式的 Martinelli Xtt, φ, 混合密度, 沸腾区压降, 动能损失等）

    -- RecordMixin 字段
    sign_status VARCHAR(30) NOT NULL,
    record_hash VARCHAR(64) NOT NULL,
    approval_step INT,
    approval_depth INT,
    approval_role VARCHAR(30),
    locked_by_deliverable BOOLEAN DEFAULT FALSE,
    imported_from_workspace_id UUID,
    created_by UUID,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP,

    UNIQUE(project_id, equipment_tag)
);
字段说明：

inlet_pipe_params 示例结构：

json
{
  "mass_flow_kg_per_h": 1612800,
  "density_kg_per_m3": 865,
  "velocity_m_per_s": 2.6377,
  "inner_diam_m": 0.25,
  "equivalent_length_m": 97.4,
  "friction_factor": 0.008015,
  "reynolds": 17001827.6,
  "pressure_drop_const": 1.1074,  // P11
  "pressure_drop_coeff": 0.01137   // P12 系数（乘以 Hx）
}
outlet_pipe_params 类似，增加 vapor_fraction、mixture_density、mixture_viscosity 等。

shell_side_params 包含 avg_density、static_head、friction_drop 等。

other_params 用于存储立式热虹吸特有的 Martinelli 参数、φ 因子、沸腾区压降、动能损失等。

第四部分：验收标准
验收项	标准
汽包计算	steam_drum_results 表包含汽包工艺计算 ≥ 90% 的字段（旋分器、给水分布器、蒸汽空间容积负荷）
两相流管径	two_phase_pipe_sizing_results 表包含上升管/下降管两相流管径计算的全部关键字段
排污扩容器	blowdown_drum_results 表支持排污扩容器的热量回收和容积设计
热虹吸循环安装高度	thermosiphon_circulation_results 表支持卧式/立式蒸汽发生器安装高度计算的全部关键字段（几何参数、管线压降、静压头、最终高度、校核结果）
电力消耗	utility_power_items 表支持按电压分级统计
燃料气	utility_fuel_gas 表支持初期/末期/最大工况
热交换	utility_heat_exchange 表支持按温度等级分类（>120℃/<120℃）
综合能耗	utility_energy_summary 表支持电/燃料/蒸汽/水/气体/低温余热六类能耗折算
催化剂	catalyst_loading 表支持催化剂装填量和寿命管理
导入能力	汽包计算 Excel、安装高度 Excel 和能耗 Excel 可导入 PCS 并映射到对应字段（SUP-008 扩展）
