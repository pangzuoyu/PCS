第一部分：引言
1.1 目的
本文档定义P6阶段（高级计算模块第三批）的完整需求规格，明确CV调节阀、RESTRICTION节流装置、FLARE_SYS火炬系统、COOL_TOWER冷却塔、PSYCHRO湿空气计算、OPEN_CHANNEL明渠流和FILTRATION/COST_EST七个模块的详细功能需求、算法规格和验收标准。

1.2 文档范围
包含：

CV：调节阀Cv计算、阻塞流校核、孔板计算

RESTRICTION：限流孔板、文丘里管、喷嘴、多级降压

FLARE_SYS：泄放汇总、总管尺寸、分液罐、火炬筒体

COOL_TOWER：Merkel法热力计算、补充水量、风机功率

PSYCHRO：湿空气性质计算（CoolProp HumidAir）

OPEN_CHANNEL：明渠流量、断面设计、临界水深

FILTRATION：板框/转鼓/带式过滤计算

COST_EST：设备成本估算

不包含：

EQUIP_LIST/UTIL/EQUIP_LIB集成（P7阶段）

报表输出（P8阶段）

签署流程前端（P9阶段）

第二部分：综合描述
2.1 产品前景
P6阶段交付第三批高级计算模块，填补了系统在流体控制、安全泄放、公用工程和排水等领域的计算空白。这些模块主要依赖fluids库的成熟能力（CV/RESTRICTION/OPEN_CHANNEL），部分需自研（FLARE_SYS/COOL_TOWER）。

模块	核心功能	依赖
CV	Cv计算、阻塞流校核、孔板计算	fluids.control_valve + fluids.flow_meter
RESTRICTION	限流孔板/文丘里/喷嘴/多级降压	fluids.flow_meter + FLASH
FLARE_SYS	泄放汇总/总管/分液罐/筒体/辐射	自研 + fluids.compressible + PSV结果
COOL_TOWER	Merkel热力/循环水量/补充水/风机	自研 + PSYCHRO

FILTRATION	过滤面积/周期/压降	SciPy + 自研
COST_EST	成本估算	自研 + CONFIG数据

2.5 设计和实现上的限制
自研模块（FLARE_SYS/COOL_TOWER/COST_EST）需经工艺负责人验证后方可发布。

fluids库能力经GitHub核实，不得假设存在不存在的模块。

COST_EST结果仅作参考，不用于正式概算。

FLARE_SYS辐射计算需满足BEDD中的限值要求。

记录生命周期（V1.1，SUP-007）：各模块计算结果为计算记录——9 态门禁（FLARE_SYS 属安全相关，建议 3~4 级批准深度）、record_hash、无 version 字段；引用物流须为 CHECKED；弃用位号终身锁定。

3.2 功能需求
3.2.1 CV调节阀计算
需求编号：P6-CV-001

功能描述：实现调节阀Cv值计算和选型辅助。

计算公式（IEC 60534-2-1）：

不可压缩流体（湍流）：
Cv = Q × √(SG/ΔP)

可压缩流体：
带膨胀系数Y的修正公式

阻塞流校核：
气体：临界压比 P₂/P₁ < (2/(k+1))^(k/(k-1))
液体：闪蒸/空化校核（通过FLASH计算饱和压力）

输出：调节阀规格书（Cv值、选型、噪音预估）。

验收标准：

Cv值与IEC 60534手算偏差<1%

阻塞流判定正确

3.2.2 RESTRICTION节流装置
需求编号：P6-RES-001

功能描述：实现限流孔板、文丘里管、喷嘴和多级降压装置计算。

装置类型：

类型	计算内容	方法
限流孔板	孔径、永久压损	ISO 5167-2 + fluids.flow_meter
文丘里管	喉部直径、压差	fluids.flow_meter
喷嘴	直径、压差	fluids.flow_meter
多级降压	级数、每级孔径	逐级节流 + FLASH闪蒸校核
阻塞流校核：

气体：临界压比判定

液体：饱和压力校核（通过FLASH）

两相：HEM/滑移模型

出口物流规则（V1.2，ADR-0022）：RESTRICTION 与 CV 计算完成后自动创建出口物流（source_type=DEVICE_CALCULATED、sign_status=DRAFT、change_type=ISOENTHALPIC/FRICTION_PRESSURE_DROP），物流号经过节流装置后更换，血缘记录 {上游物流}--[装置]-->{出口物流}。

验收标准：

与ISO 5167手算偏差<1%

临界流判定与fluids结果一致

3.2.3 FLARE_SYS火炬系统
需求编号：P6-FLR-001

功能描述：实现火炬系统的基础工艺计算。

计算内容：

计算项	说明	方法
泄放量汇总	多PSV同时泄放叠加	从PSV结果读取
火炬总管尺寸	总管直径、压降	Mach数法/API 521
分液罐尺寸	液滴分离	Souders-Brown
水封罐	液封高度	压差平衡
火炬筒体高度	辐射限值	API 521简化法/Brzustowski-Sommer
火炬头选择	出口速度、消烟蒸汽	API 537
辐射校验	地面辐射值	BEDD限值
验收标准：

Mach数计算与API 521手算偏差<2%

辐射计算与FlareSim偏差<10%

3.2.4 COOL_TOWER冷却塔
需求编号：P6-CT-001

功能描述：实现冷却塔热力计算和选型辅助。

计算内容：

冷却能力：从HEAT汇总循环水热负荷

循环水量：Q = H/(ρ×Cp×ΔT)

补充水量：蒸发损失+风吹损失+排污损失

塔型选择：逆流/横流，机械通风/自然通风

风机功率：基于水量和压头

飘水率：经验值（CONFIG配置）

验收标准：

蒸发损失与手算偏差<5%

补充水量与经验值偏差<10%

3.2.5 PSYCHRO湿空气计算
需求编号：P6-PSY-001

功能描述：基于CoolProp HumidAir实现湿空气性质计算。

计算类型：

类型	输入	输出
含湿量	T, RH	HumidityRatio
露点	T, RH	DewPoint
湿球温度	T, RH或焓	WetBulb
焓	T, RH	Enthalpy
比容	T, RH	SpecificVolume
冷却盘管	入口/出口条件	显热/潜热量
验收标准：与ASHRAE Psychrometric Chart偏差<1%

3.2.6 OPEN_CHANNEL明渠流
需求编号：P6-OC-001

功能描述：基于fluids.open_channel实现明渠排水计算。

计算内容：

Manning公式流量计算

梯形/矩形断面最优设计

临界水深和Froude数判定

水跃计算

跌水计算

截洪沟设计

验收标准：

Manning公式与手算偏差<1%

临界水深判定正确

3.2.7 FILTRATION过滤计算
需求编号：P6-FIL-001

功能描述：实现板框/转鼓/带式过滤的基础计算。

过滤类型：

板框过滤：面积、板数、周期

转鼓真空过滤：鼓面积、转速

带式过滤：带宽、带长

深层过滤：床深、压降

验收标准：过滤面积计算与手算偏差<5%

3.2.8 COST_EST成本估算
需求编号：P6-CST-001

功能描述：实现设备成本的相对估算。

估算方法：

基于设备类型和关键参数（面积、重量、功率）

历史成本数据+成本指数调整

多种成本关联式（CONFIG定义）

约束：仅作相对比选参考，不用于正式概算。

验收标准：估算结果与历史数据偏差<±30%（参考级精度）
